# Laravel Menus — Overview

`squipix/laravel-menus` is a lightweight Laravel package for creating and
rendering application menus. It provides a fluent menu builder, a flexible
presenter system for rendering (Bootstrap, AdminLTE, Foundation, and custom
presenters), and publishable configuration and view templates.

Why use this package:

- Simple builder API (`Menu::make`, `add`, `url`, `route`, `dropdown`).
- Presenter-driven rendering for consistent HTML across themes.
- Publishable config and views for easy customization.
- Compatible with Laravel 8–12 and PHP ^8.2.
